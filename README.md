# Quick Open & Command Palette

Fast fuzzy file finder and interactive command execution palette (Ctrl+P)

## Details
- **Identifier**: `matn.ext.filepicker`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Quick Open & Command Palette**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-filepicker
```
